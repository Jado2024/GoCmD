# Maquette A4 des OF — non contractuelle

Cette maquette PDF indépendante montre 5 pages A4 : salon mixte neuf pièces
(8+1), matelas sept pièces (7), matelas onze pièces (8+3).
Les matelas **n'ont aucun dessin**. Les gabarits sont des croquis indicatifs,
non des plans de découpe vérifiés. Les numéros sont fictifs.
La maquette ne prouve pas que l'impression Chrome/Edge depuis GoCmd produit
le même rendu : une recette navigateur/imprimante est encore indispensable.
